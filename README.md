<h3 align="center">Coffee, code, repeat.</h3>

I build product UIs in TypeScript and React, usually Next.js apps where the design system, the bundle size and the keyboard path all have to hold up at once. Vite and Tailwind are my default tools, and I care more about what ships to a slow phone than what looks good in a design review. Most of what I know about accessibility I learned watching people use interfaces I'd built.
